## 2. 공통 스토리 뼈대 (9개 모두 이 순서를 따름)
```

  ├ 메커니즘: "치실보다 97배 얇은 초미립 하이알루로닉 입자" → 틈까지 침투 → 씻어냄 (분자 3D, 거품 애니)

  └ 사용: "자기 전 한 포 입에 털어넣기만"                                (중년 여성 스틱 섭취 컷)
OFFER (마지막 8~12초, 문구 5~8개)
  ├ 제품명 공개: 헥사큐 아쿠아메딘 (박스 손에 든 컷)
  ├ 명분: 국내 런칭 기념 / 100만포 돌파 / 추석 특가

  └ CTA: 지금 바로 확인해보세요! (외곽선형 빨강/초록)
```

## 4. 자막 스타일 사용 규칙 (문구 단위 단색)
- **outline(박스 없음, 검정 외곽선)**: 훅 첫 2~4문구, 제품명, 가격/CTA
- **box(검정 박스)**: STORY 구간 전반
- **serif_story(명조)**: 사과문·스토리형 훅(1087, 2841 도입부)
- 색: 노랑=사실/전환, 빨강=문제/공포/긴급, 초록=해결/혜택, 하늘=성분/제품/기술, 흰=연결

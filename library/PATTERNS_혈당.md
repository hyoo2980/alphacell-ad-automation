## 2. 광고 메시지 (HSO)
**훅 유형 (반복 사용 = 성과 검증된 것으로 추정)**
1. **보증/도발형** — "장담하는데, 이거 먹고도 혈당 안 잡힌다? 판매 중단 / 100만원 드리겠습니다" (5·15·15B·56번, 4편)
2. **증상 질문형** — "밥만 먹으면 졸리시죠?" / "밥만 먹으면 저리던 손발" (39·56·15B)
3. **사과·반전형** — "혈당 수치만 잠깐 내리는 영양제를 찾고 계셨다면 죄송합니다" (53번)

**스토리 뼈대 (6편 공통)**
문제(식후 혈당 스파이크·식곤증·손발 저림·합병증 공포) → 기존 제품 부정(오르고 나서 먹는 영양제, 수치만 낮춤) → 적(쌀밥 당지수, 끈적한 당독소, 지친 췌장) → 성분(일본 장수마을 **자색고구마 안토시아닌**, 블루베리 18배, 독일산 **귀리 베타글루칸**) → 차별점(**밥 위에 뿌려** 당지수 자체를 낮춤) → 증명(임상, 13년 연구, 품절 대란, 약사도 먹음) → 후기(3~5일 만에) → 오퍼(비밀 링크, **62% 할인**, 오늘 자정/재고 100개, 100% 환불)

## 3. 자막 스타일 (config/styles/hyeoldang.json)
- 폰트 **Gmarket Sans TTF Bold, 이탤릭(기울임)**
- 본문: **검정 박스 + 흰 글자, 핵심어만 색** (문구 전체가 아니라 단어 단위) — 초록(해결·기간), 빨강(문제·수치), 노랑(성분·숫자), 보라(제품명), 분홍(자색고구마)
- 오퍼/CTA: 박스 없는 외곽선형 (초록·노랑 이탤릭)
- 헤드라인 3줄: ①노랑 ②빨강+초록 혼합 ③**보라 그라데이션** 제품명
- 고지문구 상시 노출: "대본에 의해 연출된 장면이며, 제품의 효과는 체질에 따라 다를 수 있습니다"

## 4. TTS 스타일
- 대부분 **남성 내레이터, 높고 힘 있는 톤** (기본 음높이 150~165Hz = 남성 치고 높은 흥분형), 53·39번은 더 높음(여성 또는 매우 흥분된 남성)
- 속도 빠름(6~7자/초), 문장 끝을 끌어올리는 홈쇼핑형, "장담하는데"/"서두르세요" 구간 강세
- ElevenLabs v3 권장 설정: stability 0.5(Natural), 훅·CTA 에 `[excited]` 태그

## 5. 표현 위험 (brands/alphacell.json 의 claims_risky)
참고영상의 **"췌장을 20대로 되돌림 / 인슐린 기능 재생 / 당뇨·합병증 / 혈관 스케일링 / 100% 환불 / 판매 중단 / 임상"** 은
식품 광고의 질병 치료·재생 표방 또는 근거 필요 표현. v01 은 이 표현들을 빼고 "식후 혈당 관리" 중심으로 작성함.
